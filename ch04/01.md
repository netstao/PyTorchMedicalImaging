# 张量
1. 张量就是一个多维数组，在深度学习中，我们经常用到多维张量来表示数据。
2. 在PyTorch中，张量（Tensor）是所有神经网络运算的基础数据结构。

## 0维张量
1. 标量
## 1维张量
1. 向量
## 2维张量
1. 矩阵
## 3维张量
1. 立方体
## 4维张量
1. 立方体堆叠
## 5维张量
1. 立方体堆叠堆叠

### 从列表到张量
1. 一个普通的python列表
```python
a = [1, 2, 3]
a[0]
```
2. 产生一个PyTorch张量
```python
import torch
a = torch.ones(3)
a #输出一下张量的结果
tensor([1,1,1])
```
3. 一些简单操作
```python
a[1] ###按位置索引访问元素
float(a[1]) #强行转为浮点数

a[2] = 2.0
a
out: tensor([1., 1., 2.])
```
